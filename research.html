Research outcomes

Our RNA-seq work asks a simple question, and Lumi is where the answer goes next.

  1. Can synthetic data help RNA-seq classification?Ensemble synthetic data generation methods for gene expression data (ongoing).
  2. Which generator should we use?MLDS, a machine learning-driven framework for ensemble synthetic data selection.
  3. Can one model do it for any table?Lumi, a bio-tabular foundation model, starting with synthetic data generation.
